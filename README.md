## Deutsch

Diese Sammlung vereint Dokumente und Zusammenfassungen zur Geschichte der **Burg Hardenburg** in der Pfalz (Bad Dürkheim), Deutschland. Sie wird im Umfeld des Heimatvereins Hardenburg gepflegt.

**Aufbau**

- Hauptsprache ist Deutsch (Dateien mit Endung `_de`); zu jeder Datei gibt es gleichnamige Fassungen auf Englisch (`_en`) und Russisch (`_ru`).
- [Quellenliste](references.md): gemeinsame, sprachunabhängige Liste aller verwendeten Quellen (auch fremdsprachige).
- [Quellenzusammenfassungen](ref-summaries/): ein Unterordner je Quelle mit Zusammenfassungen in drei Sprachen, z. B. [REF-001](ref-summaries/ref-001/ref-001_de.md) (Höhn zu den Grafen von Leiningen bis 1317/1318).
- Bilder ohne Sprachbezug werden von allen Sprachfassungen gemeinsam genutzt; sprachabhängige Bilder erhalten übersetzte Kopien mit Sprachendung, bis dahin gilt die deutsche Fassung.

## English

This is a collection of documents and summaries on the history of **Hardenburg Castle** in the Palatinate (Pfalz, Bad Dürkheim), Germany. It is maintained in the context of the Heimatverein Hardenburg (local history society).

**Structure**

- German is the main language (files ending in `_de`); every file has equally named English (`_en`) and Russian (`_ru`) versions.
- [Reference list](references.md): a common, language-independent list of all sources used, including non-German ones.
- [Source summaries](ref-summaries/): one subfolder per source with summaries in three languages, e.g. [REF-001](ref-summaries/ref-001/ref-001_en.md) (Höhn on the Counts of Leiningen up to 1317/1318).
- Language-neutral images are shared by all versions; language-dependent images get translated copies with a language suffix, and the German version is used until they exist.

## Русский

Это собрание документов и резюме по истории **замка Харденбург** в Пфальце (Бад-Дюркхайм), Германия. Оно ведётся при краеведческом обществе Hardenburg (Heimatverein).

**Структура**

- Основной язык – немецкий (файлы с окончанием `_de`); для каждого файла есть одноимённые версии на английском (`_en`) и русском (`_ru`).
- [Список источников](references.md): общий языконезависимый список всех использованных источников, в том числе не на немецком.
- [Резюме источников](ref-summaries/): отдельная подпапка для каждого источника с резюме на трёх языках, например [REF-001](ref-summaries/ref-001/ref-001_ru.md) (Хён о графах Лайнингенских до 1317/1318).
- Нейтральные к языку изображения общие для всех версий; изображения с текстом получают переведённые копии с языковым суффиксом, пока их нет – используется немецкая версия.
